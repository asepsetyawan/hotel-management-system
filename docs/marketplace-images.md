# Marketplace images

Generated on 2026-10-31 with the built-in `image_gen` tool. These photorealistic scenes depict fictional demonstration properties and rooms. They are not photographs of actual hotels.

The JPEG delivery files live in `public/assets/images/`. Property images are mapped by slug in `config/marketplace.php`, so filtering the marketplace does not change a property's image. Unmapped properties use the bedroom image. Room types currently share the demonstration bedroom image.
